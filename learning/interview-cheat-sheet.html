🎯 تقلب‌نامه جامع مصاحبه فنی (Interview Cheat Sheet)

پروژه: Network Health Check Automation System (Python + Cisco pyATS + FastAPI + Docker)

۱. معرفی ۲ دقیقه‌ای پروژه در شروع مصاحبه (Elevator Pitch)

  1. معماری کلی (Modular Monolith): سیستمی با اصول Clean Architecture نوشتم که وضعیت واقعی روتر سیسکو (Actual State) را با وضعیت مورد انتظار در فایل YAML (Expected State) مقایسه و گزارش PASS / FAIL تولید می‌کند.
  2. لایه Core Domain: مدل‌های تغییرناپذیر را با @dataclass(frozen=True) و Validatorها را به صورت Pure Functions بدون وابستگی به شبکه نوشتم.
  3. جداسازی شبیه‌ساز آفلاین از روتر واقعی: با ABC یک اینترفیس NetworkDeviceConnector ساختم که دو پیاده‌سازی دارد: شبیه‌ساز آفلاین (SimulatedIosXeDevice) برای CI/CD و کانکتور واقعی (PyAtsRealDeviceConnector) با Unicon SSH و متغیرهای محیطی امن %ENV{...}.
  4. پارس کردن دستورات با Cisco Genie: به جای Regex دستی، از Parserهای رسمی Genie برای show interfaces و show ip route استفاده کردم.
  5. هم‌زمانی، دیتابیس و API: اجرای هم‌زمان چند روتر را با ThreadPoolExecutor و asyncio.to_thread (به همراه Timeout و Error Isolation) نوشتم، نتایج را با Parameterized SQL در SQLite ذخیره کردم و با FastAPI و Docker سرو کردم.

۲. سؤالات قطعی مصاحبه: Concurrency و قفل GIL (فاز ۷)

سؤال ۱: قفل GIL در پایتون چیست و چرا Threading برای SSH زدن به ۱۰۰ روتر سرعت را بالا می‌برد؟
قفل GIL (Global Interpreter Lock) در CPython اجازه می‌دهد در هر لحظه فقط یک Thread بایت‌کد پایتون را روی CPU اجرا کند. اما چون SSH زدن به روتر یک کار I/O-Bound است، مفسر پایتون در تمام لحظاتی که منتظر پاسخ شبکه است قفل GIL را آزاد می‌کند تا سایر Threadها به روترهای دیگر درخواست بفرستند. برای کارهای محاسباتی سنگین (CPU-Bound) از Multiprocessing (ProcessPoolExecutor) استفاده می‌کنیم تا هر پروسه GIL و هسته CPU مستقل خودش را داشته باشد.
سؤال ۲: اگر یک تابع Synchronous را مستقیم داخل async def صدا بزنیم چه می‌شود؟
کل Event Loop تک‌نخی قفل (Block) می‌شود! برای جلوگیری از بلاک شدن Event Loop باید آن را با await asyncio.to_thread(sync_func, arg) (معادل withContext(Dispatchers.IO) در کاتلین) به یک Thread پس‌زمینه بفرستیم.
مدل در Python معادل در Kotlin کاربرد اصلی رفتار با GIL
ThreadPoolExecutor Dispatchers.IO I/O-Bound (شبکه، SSH، فایل) در زمان انتظار شبکه آزاد می‌شود
ProcessPoolExecutor پروسه‌های مستقل OS CPU-Bound (پردازش سنگین) هر پروسه GIL مستقل خودش را دارد
asyncio (async/await) Kotlin Coroutines وب‌سرور FastAPI و I/O ناهمگام تک‌نخی؛ نیازمند asyncio.to_thread برای کد همگام

۳. سؤالات قطعی مصاحبه: FastAPI، SQLite، Docker و معماری (فازهای ۶ و ۸)

سؤال ۳: چرا FastAPI را به جای Flask یا Django انتخاب کردید؟
۱) اعتبارسنجی خودکار JSON ورودی با Pydantic بر اساس Type Hints و برگرداندن خودکار کد 422 Unprocessable Entity در صورت خطای ورودی.
۲) پشتیبانی بومی از async / await (استاندارد ASGI).
۳) تولید خودکار مستندات تعاملی Swagger UI در مسیر /docs.
سؤال ۴: چرا در کوئری‌های SQL نباید از f-string استفاده کنیم؟
چون باعث آسیب‌پذیری SQL Injection می‌شود (مفسر SQL ورودی کاربر را با دستور اجرایی قاطی می‌کند). راه‌حل استاندارد استفاده از Parameterized Queries با علامت سؤال (WHERE run_id = ?) است.
سؤال ۵: چرا پروژه را با Modular Monolith شروع کردید نه Microservices؟
چون در مقیاس اولیه از Over-Engineering و Network Latency جلوگیری می‌کند و ماژول‌ها در حافظه با هم در ارتباط هستند؛ اما چون مرز پکیج‌ها (api, core, devices, database) کاملاً جداست، در مقیاس بالا به‌راحتی به کانتینرهای میکروسرویس مجزا شکسته می‌شود.
سؤال ۶: چرا داخل کانتینر Docker باید وب‌سرور را روی 0.0.0.0 اجرا کنیم نه 127.0.0.1؟
چون هر کانتینر Docker شبکه مجازی خودش را دارد و 127.0.0.1 فقط از داخل خود کانتینر قابل دسترسی است. برای دریافت ترافیک از بیرون کانتینر باید روی 0.0.0.0 گوش بدهد.

۴. سؤالات قطعی مصاحبه: Python، pyATS، Genie و شبکه (فازهای ۱ تا ۵)

سؤال ۷: چرا در @dataclass از field(default_factory=dict) به جای = {} استفاده می‌کنیم؟
چون مقدار پیش‌فرض مستقیم فقط یک بار در زمان تعریف کلاس ساخته می‌شود و بین تمام نمونه‌ها مشترک می‌شود؛ اما default_factory=dict برای هر نمونه یک دیکشنری جدید می‌سازد.
سؤال ۸: تفاوت pyATS (AEtest)، Genie و Unicon چیست؟
• AEtest: فریم‌ورک چرخه حیات تست (CommonSetup، Testcase، CommonCleanup — معادل JUnit).
• Genie: کتابخانه پارس کردن خروجی متنی دستورات روتر به دیکشنری ساختاریافته پایتون (با output=raw_text به صورت ۱۰۰٪ آفلاین هم کار می‌کند).
• Unicon: موتور اتصال SSH به روتر با State Machine هوشمند برای مدیریت Promptها و صفحه‌بندی (--More--).
